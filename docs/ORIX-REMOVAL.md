# ORIX manual removal (beta)

The current beta does not include an identified application uninstaller. This is a provisional manual procedure for the default per-user installation. On 2026-11-05, an isolated beta.2 Windows check verified all 193 installed files against staging, quit normally, removed the installation and two target-checked shortcuts, and retained the profile note unchanged. Reinstallation exited 0 and the installed note API read the retained text. Shortcut paths and hook settings were redirected into the disposable profile. This establishes the scoped filesystem procedure. Default-profile removal and notification-registration cleanup remain unverified. If you installed ORIX to another folder, identify that folder before removing anything.

1. In **ORIX Settings → Connections**, switch off any Claude Code and Codex connections you enabled. Confirm the interface reports the change; if it reports an error, stop and investigate rather than deleting or replacing either application's configuration. ORIX's hook removal is designed to preserve other hooks, but a real-profile removal has not yet been verified. If a connection control is unavailable or its state is uncertain, stop and inspect the relevant agent configuration with care; an Off or unavailable indicator alone does not prove there are no leftover hooks.
2. In the ORIX tray menu, turn off **Start with Windows** and check that it stays off, then choose **Quit ORIX**. Wait until ORIX has closed.
3. In File Explorer, open `%LOCALAPPDATA%\Programs`. Remove the `ORIX` folder only after verifying it is the installation you intend to remove. If you chose a different location, remove only that installation folder instead. Do not remove an `.old` backup that may be needed for recovery.
4. Open `%APPDATA%\Microsoft\Windows\Start Menu\Programs`. If `ORIX` and `ORIX Settings` shortcuts still exist, check that each shortcut's target points to the installation you removed before deleting it. Leave shortcuts belonging to another installation alone.
5. If you installed **ORIX Project Editor** in VS Code and no longer need it, remove that extension using VS Code's Extensions view. Its extension identifier is `twocode.project-editor`; check its identity before removal.

Your notes, settings and other ORIX profile data are kept separately from the program under the Electron user-data directory, normally `%APPDATA%\ORIX`. Leave that folder in place to retain your data. Removing it permanently deletes the data it contains; back up anything you need and verify the folder before doing so. Do not remove TwoCode's folders or other applications' settings.

ORIX also registers per-user Windows notification identity entries for `app.orix.desktop` and `app.orix.settings`. This procedure leaves them in place. ORIX hook configuration backups can remain in the respective agent configuration directories and may contain sensitive data; do not share or remove them without checking. There may be other residual state; this document does not claim complete cleanup. The source project's release checklist records outstanding verification.
