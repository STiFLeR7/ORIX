## Native redistribution review: unresolved evidence

The packaged Codex voice notice identifies dynamically linked GStreamer and GLib, their licenses and upstream source records, plus a separate Microsoft Visual C++ runtime. Treat this as a release review, not a legal clearance.

The packaged Codex runtime also serves an existing feature: `chatgpt-provider.js` resolves the platform package and starts its executable as `app-server --listen stdio://` for the ChatGPT provider. Removing the entire Codex package would therefore break that provider. Static inspection alone does not establish whether the separate voice directory can be removed without affecting supported behavior; keep it in the candidate until compatibility and the remaining redistribution requirements have been assessed.

An isolated copy containing only the packaged `codex.exe` successfully printed version 0.160.0 and `app-server --help` without the voice directory. These offline help commands do not start an app-server session, authenticate, run a conversation or exercise sandbox helpers; they do not justify removing voice files from the release.

- **LGPL source and notices:** retain the bundled notice and license files. Identify the exact corresponding source, including any changes and applicable build material, and establish a source-delivery method that meets the applicable license conditions for the distribution. Recorded upstream archives and script links are evidence, but have not established complete corresponding source or durable access. See [LGPL 2.1, sections 4 and 6](https://www.gnu.org/licenses/old-licenses/lgpl-2.1.dbk).
- **Library replacement:** identify which section 6 distribution route applies and verify the chosen route's conditions, including whether compatible modified shared libraries can be used and whether applicable terms permit modification and debugging. The presence of DLLs alone does not prove this.
- **Microsoft runtime:** identify the distributor's applicable Visual Studio license and terms and verify that the unmodified runtime is eligible for redistribution. Microsoft limits distribution of these binaries to licensed Visual Studio users under its terms; see [Microsoft's redistribution guidance](https://learn.microsoft.com/en-us/cpp/windows/redistributing-visual-cpp-files) and [Visual Studio 2026 distributable-code list](https://learn.microsoft.com/en-us/visualstudio/releases/2026/redistribution). A signature or upstream inclusion is not proof of eligibility.
- **Other native components:** inventory the other shipped native binaries and their transitive components, then check their notices and terms against the exact release artifact. This review remains incomplete.

Before publication, inspect the exact proposed source manifest and artifacts again, run the release checks, and obtain publication authorization. A clean local manifest does not establish live-provider compatibility or code signing.
