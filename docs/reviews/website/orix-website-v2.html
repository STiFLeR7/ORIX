06 / The practical things

A few things
before you begin.

Get to know your desktop layer, its tools and its connections.

Read the documentation ↗
What does ORIX do?

ORIX is a free, open-source Windows desktop layer for supported AI session status, notes, clipboard history, focus tools, file references and optional Spotify controls.

Which Windows versions can I use?

Beta.3 supplies Windows 10/11 x64 artifacts. Check the selected release for its exact requirements.

Is ORIX completely free?

ORIX is free and open source under ISC. Connected AI and music services apply their own accounts, subscriptions and terms.

Where can I inspect the source?

The public ORIX repository contains the source, license, contribution guidance and release records.

Do integrations need an account?

Setup depends on the selected connection. Core local tools work independently. Optional providers and Spotify use their own authentication and service requirements.

What happens to clipboard history?

Clipboard capture is enabled by default and retains up to eight text entries in memory. Disable Clipboard in Modules and save to stop capture and clear ORIX's history. The history also clears when the process ends. The Windows clipboard is managed separately.

What happens when I hide the layer?

Enabled tools and integrations keep running. Quit ORIX to stop its running background processing. The website's visibility control illustrates this behavior using sample state.

How do updates and removal work?

Updates are manual in the current application. Follow your release's instructions and the removal guide for the program, hooks and retained profile data.

Is the Windows beta signed?

Beta.3 Windows artifacts are unsigned. Signing setup is pending. Review release checksums, known limitations and the code signing policy.
