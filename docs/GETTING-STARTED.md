# Getting started with ORIX

Launch the installed application and open **ORIX Settings** from the tray or Start menu. Choose tools in **Modules**, connect integrations in **Settings → Connections** and select Light, Dark or System appearance in **Settings → General**.

The interface uses English. See the [project README](../README.md) for source setup and use, [manual updates](UPDATES.md) for upgrading and the [removal guide](ORIX-REMOVAL.md) for uninstalling the beta.
