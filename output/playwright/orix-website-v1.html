07 / The practical things

Before you
make it yours.

A few things to know about your desktop layer.

Read the documentation
What does ORIX do?

ORIX is a free, open-source desktop layer for Windows. It brings supported AI session status, notes, clipboard history, focus tools and optional Spotify controls into a compact interface.

Which Windows versions can I use?

The beta.2 release supplies Windows 10/11 x64 artifacts. Check the release listing for the exact requirements of your selected version.

Is ORIX completely free?

ORIX is free and open source under ISC. Connected AI and music services have their own accounts, subscriptions, usage conditions and terms.

Where can I inspect the source?

The ORIX repository contains the source, license, contribution information and release records.

Do integrations need an account?

Setup depends on the integration. Core local tools can be used independently. Provider connections and Spotify use their individual authentication and service requirements.

What happens to clipboard history?

Clipboard capture is enabled by default and keeps up to eight text entries in memory. Disable Clipboard in Modules and save to stop capture and clear ORIX's history. History is also cleared when the process ends. The Windows clipboard is managed separately.

What happens when I hide the layer?

The desktop layer is hidden while enabled tools and integrations continue running. Quit ORIX to stop its running background processing.

How do updates and removal work?

Follow the instructions for your release. Updates are manual in the current application. The removal guide covers the program, hooks and retained profile data.

Is the Windows beta signed?

Beta.2 Windows artifacts are unsigned. Signing setup is pending. Review the selected release's signature information, checksums, known limitations and code signing policy.
